# Ratio — Official Logo Assets

These four PNG files are the only official Ratio logo artwork, supplied and approved by the project owner on 2026-11-15. Keep the original PNG files unchanged.

## Website theme mapping

- **Selected light theme:** use `public/brand/ratio-orbit-white-white-dot-dark-background.png` (white orbit and white dot on black background).
- **Selected dark theme:** use `public/brand/ratio-orbit-black-black-dot-light-background.png` (black orbit and black dot on white background).

This mapping is intentional and must not be reversed.

## Reserved for future plans

Keep both transparent-background originals in `public/brand/` without altering them:

## Brand rules

Do not redraw, reconstruct, substitute, stylize, recolor, crop, or create additional logo variants. Do not replace these assets with an SVG or another icon. When an implementation needs a different display size, scale the original PNG proportionally and do not overwrite the master asset.
